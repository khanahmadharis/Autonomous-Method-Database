# Autonomous-Method-Database

An interactive explainer of the fully digital analytical method lifecycle, built around a centralized method database.

Open `index.html` in a browser. It is a single self-contained page; it loads fonts from Google Fonts and three.js from cdnjs for the 3D integration view.

Sections:

- The eight-step method lifecycle
- A 3D view of the lifecycle, the lab systems underneath and the labs at the bottom
- A worked example run of one test through the whole loop (fictional names and numbers)
- The systems a method database sits between
- Eight foundations for making it work
- A plain-language glossary
